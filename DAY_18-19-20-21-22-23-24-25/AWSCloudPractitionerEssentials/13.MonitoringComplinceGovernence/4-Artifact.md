
# ✅ Benefits of Compliance with AWS

**Compliance** means ensuring that your **cloud resources and data** follow all **relevant regulations, industry standards, and internal policies**.

AWS helps organizations achieve compliance by:

* Inheriting AWS’s latest **security controls**
* Providing **third-party validation** against thousands of global requirements
* **Streamlining & automating** compliance processes
* Offering **on-demand compliance reports**

---

## ☁️ AWS Artifact

AWS Artifact provides **no-cost, on-demand access** to:

* AWS **security and compliance reports**
* Select **online agreements**

**Benefits:**

* Manage compliance at scale
* Save time with instant access to compliance reports
* Deploy with more confidence

**Use cases:**

* Manage online agreements (e.g., HIPAA)
* Assess third-party compliance validation

---

## 🔑 Types of AWS Artifact

| Type                        | Description                                                                                                                                                | Example Use Case                                                         |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **AWS Artifact Agreements** | Lets organizations review, accept, and manage agreements for individual accounts or across AWS Organizations. Supports specific regulations (e.g., HIPAA). | A healthcare company signing HIPAA-related agreements with AWS           |
| **AWS Artifact Reports**    | Provides compliance reports from third-party auditors who validate AWS against global standards. Can be shared with auditors or regulators as proof.       | A development team downloading a SOC 2 report to meet audit requirements |

---

## 📚 AWS Compliance Portal

The **AWS Compliance portal** provides resources like:

* Customer compliance case studies
* Compliance whitepapers and documentation
* Answers to **key compliance questions**
* Overviews of **AWS risk and compliance**
* An **auditing security checklist**

# AWS Governance & Compliance Matrix

| Stage              | Purpose                                                                                              | Key AWS Services                                                                                                                                                                                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Secure 🔒**      | Protect data, systems, and infrastructure from unauthorized access, disruption, or modification.     | - **IAM** (Identity & Access Management)<br>- **IAM Identity Center** (SSO)<br>- **Secrets Manager** (store credentials)<br>- **AWS KMS** (encryption keys)<br>- **AWS Shield** (DDoS protection)<br>- **AWS WAF** (Web App Firewall)<br>- **AWS Certificate Manager** (TLS/SSL)<br>- **Amazon Macie** (sensitive data protection) |
| **Monitor 👁️**    | Continuously observe resources, system activity, and network traffic to detect threats or anomalies. | - **Amazon CloudWatch** (metrics, logs, dashboards, alarms)<br>- **Amazon GuardDuty** (threat detection)<br>- **Amazon Detective** (threat investigation)<br>- **AWS Security Hub** (centralized security findings)<br>- **AWS Systems Manager** (ops monitoring & automation)                                                     |
| **Audit 📋**       | Track and review activities for accountability and compliance evidence.                              | - **AWS CloudTrail** (user & API activity tracking)<br>- **Amazon Inspector** (vulnerability scans)<br>- **AWS Config** (resource compliance & history)<br>- **CloudTrail Insights** (detect anomalies in activity)                                                                                                                |
| **Compliance 🏛️** | Ensure adherence to regulatory, industry, and organizational requirements.                           | - **AWS Artifact** (compliance reports & agreements)<br>- **AWS Audit Manager** (automated audit evidence)<br>- **Compliance Programs** (regulatory certifications)<br>- **Third-party attestations** (e.g., PCI, HIPAA, ISO, SOC)                                                                                                 |
