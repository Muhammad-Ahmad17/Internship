## **AWS Support Plans Comparison**

| **Plan**                    | **Recommended For**                                         | **Response Times**                                                                 | **Trusted Advisor**                          | **TAM (Technical Account Manager)**         |
|------------------------------|------------------------------------------------------------|------------------------------------------------------------------------------------|-----------------------------------------------|---------------------------------------------|
| **Basic Support**            | All AWS customers (default)                                | - < 24 hrs for general guidance<br>- < 12 hrs when systems impaired                 | Core checks only                              | Not included                                |
| **Developer Support**        | Experimenting or testing in AWS                            | Includes Basic +                                                                   | Core checks only                              | Not included                                |
| **Business Support**         | Minimum tier for production workloads                      | Includes previous +<br>- < 4 hrs when production system impaired<br>- < 1 hr when production system is down | Full set of checks                            | Not included                                |
| **Enterprise On-Ramp**       | Production & business-critical workloads                   | Includes previous +<br>- < 30 min when business-critical system is down             | Full set of checks                            | Pool of TAMs provide proactive guidance      |
| **Enterprise Support**       | Business-critical & mission-critical workloads             | Includes previous +<br>- < 15 min when business/mission-critical system is down     | Full set + prioritized recommendations        | Dedicated TAM with consultative guidance     |
