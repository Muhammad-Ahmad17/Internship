
# Amazon DocumentDB

Amazon DocumentDB (with MongoDB compatibility) is a fully managed database service designed for semistructured data—information that doesn’t conform to rigid relational schemas. It manages JSON-like documents with dynamic schemas, making it ideal for applications that require flexibility and rapid iteration.

## Key Features

### MongoDB Compatibility

* Fully compatible with MongoDB workloads
* Supports MongoDB APIs, drivers, and tools
* Minimal changes required to migrate existing MongoDB applications

### Performance and Scalability

* Automatic storage scaling up to 64 TB in 10 GB increments
* Handles millions of requests per second with consistent performance
* Compute resources can be scaled up or down as needed

### Increased Read Throughput

* Supports up to 15 read replica instances sharing underlying storage
* Improves read performance for high-volume applications

### Security and Reliability

* Continuous backups for point-in-time recovery
* Enterprise-grade security features (encryption at rest and in transit, network isolation)
* Multi-AZ deployments for high availability

## Use Cases

* Content management systems
* Catalog and inventory management
* User profile and personalization systems
