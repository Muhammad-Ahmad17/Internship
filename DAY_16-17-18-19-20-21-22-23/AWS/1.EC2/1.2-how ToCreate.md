
  # Launching an Amazon EC2 Instance

 [Watch a tutorial on how to launch an EC2 instance and run it locally using an SSH key.](https://youtu.be/S5B09dq-jGQ?si=6DSaEbKLp9By1Nc5)


## Launch an EC2 Instance and Connect via SSH Key

### **1. Log in to AWS Management Console**

* Go to [AWS Console](https://aws.amazon.com/console/).
* Search for **EC2** in the search bar and open it.

---

### **2. Launch a New Instance**

* Click **Launch Instance**.
* **Name**: Give your instance a name (e.g., `MyEC2`).
* **AMI (Amazon Machine Image)**: Select **Amazon Linux 2023** or **Ubuntu** (recommended for learning).
* **Instance type**: Choose `t2.micro` (Free Tier eligible).
* **Key pair**:

  * Create a new key pair.
  * Download the `.pem` file (keep it safe — AWS will not give it again).
* **Network settings**:

  * Allow **SSH** traffic from your IP.
* Click **Launch Instance**.

---

### **3. Locate Your Instance**

* In the EC2 dashboard, click **Instances** in the sidebar.
* Wait until the **Instance State** is **Running**.

---

### **4. Connect via SSH (Local Machine)**

1. Open a terminal on your local computer.
2. Navigate to the directory where your `.pem` key is saved.
3. Set proper file permissions:

   ```bash
   chmod 400 my-key.pem
   ```
4. Connect to the EC2 instance:

   ```bash
   ssh -i my-key.pem ec2-user@<Public-IP>
   ```

   * Replace `<Public-IP>` with the public IPv4 address of your instance.
   * For **Ubuntu** AMI, use `ubuntu` instead of `ec2-user`:

     ```bash
     ssh -i my-key.pem ubuntu@<Public-IP>
     ```

---

### **5. Verify Connection**

* You should see something like:

  ```bash
  [ec2-user@ip-xx-xx-xx-xx ~]$
  ```
* Now you can run Linux commands directly on your EC2 instance.

---

### **6. Stop or Terminate the Instance**

* **Stop**: Saves data but stops billing for compute time.
* **Terminate**: Deletes the instance and attached storage.

# Connect to Windows EC2 Instance via Remmina (Linux)

## Prerequisites
- An **AWS Windows EC2 instance** running.
- **Public DNS** or **Public IP** of your instance.
- **Administrator password** for the instance (retrieved from AWS Console using your `.pem` key file).
- Remmina installed on your Linux system:
  ```bash
  sudo apt install remmina
## 1. Retrieve the Windows Password

1. Go to the **AWS Console** → **EC2** → **Instances**.
2. Select your **Windows instance**.
3. Click **Connect** → **RDP client**.
4. Click **Get password**.
5. Upload your `.pem` key file and click **Decrypt Password**.
6. Copy the decrypted password — you'll need it for Remmina.

---

## 2. Open Remmina and Create a Connection

1. Launch **Remmina**.
2. Click **+** (New connection profile) or use **Quick Connect**.
3. Fill in the following fields:

| Field        | Value Example                                                     |
| ------------ | ----------------------------------------------------------------- |
| **Protocol** | RDP - Remote Desktop Protocol                                     |
| **Server**   | `ec2-18-222-45-67.us-east-2.compute.amazonaws.com` (or Public IP) |
| **Username** | `Administrator`                                                   |
| **Password** | *Your decrypted password*                                         |
| **Domain**   | *(Leave empty)*                                                   |

---

## 3. Adjust Display Settings

* Under **Resolution**:

  * Select **Use client resolution** for full screen
    **OR**
  * Select **Custom** (e.g., `1920x1080`).
* (Optional) Check **Span screen over multiple monitors** if you have more than one.

---

## 4. Connect

* Click **Save and Connect** (or **Connect** for Quick Connect).
* Accept the certificate warning if prompted.
* Your Windows desktop will appear.

---

## 5. Full Screen Toggle

* While connected, press:

  ```
  Ctrl + Alt + Enter
  ```

  to switch between windowed and full screen.

---

## 6. Disconnect

* Close the Remmina tab or press:

  ```
  Ctrl + Q
  ```
* If you no longer need the instance, **stop it in AWS Console** to avoid charges.

---

**Tip:** Always stop your EC2 instance when not in use to avoid hourly billing.
